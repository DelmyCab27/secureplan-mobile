# SecurePlan Mobile

App móvil de **SecurePlan Mobile**, una agenda para organizar tus actividades diarias y mejorar tu productividad. Este repositorio es la aplicación del celular: desde aquí el usuario inicia sesión, ve su calendario, crea sus eventos y recibe recordatorios.

Proyecto integrador de la asignatura Desarrollo Móviles Integral.

## Qué hace

- Permite registrarse e iniciar sesión.
- Muestra los eventos del usuario en un calendario.
- Permite crear, editar y borrar eventos.
- Envía recordatorios al celular.
- Sigue funcionando de forma controlada cuando no hay conexión a internet.

## Tecnologías

- React Native
El servidor está en el repositorio [secureplan-backend](https://github.com/DelmyCab27/secureplan-backend).

## Cómo ejecutarla

1. Instala Node.js.
2. Instala las dependencias con `npm install`.
3. Copia el archivo `.env.example` a `.env` y pon la dirección del servidor.
4. Inicia la app con `npx react-native start` y córrela en un emulador o en un celular.

Para que funcione, el servidor debe estar corriendo.
